# Thư mục Bộ nhớ Tạm thời (Temporary Working Memory)

Thư mục này dùng để lưu trữ trạng thái làm việc, ngữ cảnh tạm thời và ghi chú nháp của các AI Agent khác nhau khi vận hành trên kho tri thức **Eco Learning**.

## 📂 Các file Bộ nhớ hiện có
- **`antigravity_memory.md`**: Bộ nhớ làm việc & ghi chú tạm dành riêng cho AI Agent **Antigravity** (Gemini).
- **`codex_memory.md`**: Bộ nhớ làm việc & ghi chú tạm dành riêng cho AI Agent **Codex**.

## 📌 Quy tắc sử dụng
- Mỗi AI Agent khi vận hành sẽ đọc/ghi vào file memory tương ứng với tên model của mình.
- Nội dung trong thư mục này chỉ mang tính chất bộ nhớ tạm thời (working memory / scratchpad), không thay thế các tài liệu nhật ký chính thức (`LEARNED.md`, `RELATE.md`, `GLOSSARY.md`).
